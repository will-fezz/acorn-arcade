# Sweetcorn Arcade 2026.11.1

1. Keep the console charging and connected to Wi-Fi.
2. Choose Settings → Update firmware.
3. After restart, check About shows 2026.11.1 and leave it running for a full minute.
4. In More games, request several games quickly, then swipe over asked rows. The list should stay in place and still scroll.
5. Confirm each request appears once in Settings → Downloads and still needs grown-up approval.

This release fixes rapid-tap screen rebuilding and swipes over asked rows. It retains firmware 7’s download-memory and retained-save management changes. Automated tests and build passed; physical-console crash freedom is not yet verified. If a freeze or reboot persists, capture serial logs.

Existing game and theme packs are unchanged. New game-owned packs remain withheld pending console confirmation. Do not erase the console or saved progress as an update workaround.

The public version is 2026.11.1; its numeric OTA image/catalogue version is 20261101 for compatibility with older firmware. Firmware rollback protection remains in place.
