Already running Sweetcorn?

Use Settings → Update firmware on the console for a normal update that keeps your data. This website is for a fresh installation or recovery, not a save-preserving update.

Before you connect

  1. Use desktop Google Chrome or Microsoft Edge on Mac or Windows. Safari and iPhone/iPad browsers are not supported by this installer.
  2. Check the board is the Waveshare ESP32-S3-Touch-AMOLED-1.75C with 32 MB flash. Other ESP32-S3 boards are not supported, even if the browser can connect to them.
  3. Connect the console with a USB data cable. Close serial monitors and other apps using the device.

Fresh install erases the console

This removes Wi-Fi settings, PIN, play history, saved progress and downloaded games/themes. It also replaces any other firmware. There is no backup or undo in this installer.

Afterwards, set up Wi-Fi on the console and download your theme and games again.

After installation

Wait for the installer to finish, then restart the console. If it remains in download mode, disconnect and reconnect USB without holding BOOT. Check About shows 2026.11.14.

This is the current released console firmware. Experimental companion support requires the configured private service and provisioned app. Real-console pairing remains unverified. Browser flashing has been checked in software; physical Mac/Windows installation still needs testing.

My console doesn’t appear

Try a different data cable or USB port and close any serial monitor. If necessary, hold BOOT while connecting USB, then release it and reconnect in the installer. Select the console’s USB serial port, not another device. Some USB bridges need a manufacturer driver on Windows; only install the driver for your actual board.

What if installation fails?

Keep the cable connected until the installer reports completion or failure. If interrupted, enter BOOT/download mode and retry. Do not use this page for a different board. For help, save the installer error and check the project’s release notes.
